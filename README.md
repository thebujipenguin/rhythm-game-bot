# A Simple Bot for Rhythm Plus
This bot uses opencv and pyautogui to bot the rhythm plus game. Built for the Flavortown YSWS event by Hack Club. 

I used ai to fix compatability errors with my libraries, and them failing to do what I needed them to do. I also used a video by Kian Brose abt bots to help me start the project and find what libraries I needed, and learn the basics of the libaries.
